# British Top

Шкільний проєкт: рейтинг британських рок-груп з програвачем-вінілом.

## Запуск

Двічі клікнути `index.html`. Нічого встановлювати не потрібно.

## Розробка (автооновлення)

Потрібен Node.js. Один раз `npm install`, далі `npm run dev` — відкриється http://localhost:5500 і оновлюватиметься після кожного збереження файлу.

## Структура

```
index.html        розмітка сторінки
css/style.css     стилі
js/loader.js      екран завантаження (назва + ноти),попереднє завантаження відео/аудіо
js/scroll.js      плавний скрол (Lenis)
js/thanks.js      фінал «Дякуємо за увагу» + імена
js/preloader.js   прелоадер з іменами
js/ranking.js     рейтинг: групи, альбоми, міста, обкладинки, треки
js/player.js      плеєр картки (нотка, еквалайзер, керування)
js/map-scene.js   сцена: карта Європи, наїзд на Британію, картки місць
js/europe-data.js дані карти (генерується: npm run build:map)
scripts/          генератор карти
assets/covers/    обкладинки альбомів
assets/audio/     треки
assets/fonts/     шрифт Onest (OFL), лежить у проєкті
js/vendor/        Lenis (MIT), лежить у проєкті
favicon.svg       іконка сайту
```

Щоб змінити рейтинг, правте `js/ranking.js`.
